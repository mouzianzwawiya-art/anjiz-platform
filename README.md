# ANJIZ | أَنْجِز

**الشعار الرسمي:** منصتك لإنجاز أعمالك الأكاديمية والمكتبية

نسخة أولية ثابتة قابلة للنشر على GitHub Pages، بواجهة عربية RTL وتبديل لغة فعلي إلى الفرنسية والإنجليزية.

## يعمل في هذه النسخة
- تصميم متجاوب للهاتف والكمبيوتر.
- تنقل بين الأقسام، وبطاقات خدمات تفتح مساحة ملاحظات محلية.
- سوق محترفين تجريبي مع بحث ومرشحات؛ كل البطاقات والأسعار أمثلة وليست أشخاصًا أو عروضًا حقيقية.
- إنشاء مشاريع محلية وحفظها وحذفها وتصديرها إلى TXT.
- نموذج ملف مهني يحفظ محليًا فقط.
- واجهة استكشافية للمساعد الذكي دون اتصال AI.
- Manifest وService Worker بسيط مع جلب الشبكة أولًا.

## غير مفعّل بعد
لا توجد حسابات أو قاعدة بيانات أو مزامنة سحابية أو طلبات فعلية أو دفع أو عمولة. نسبة 10% اقتراح قيد الدراسة فقط. المساعد الذكي غير متصل؛ يجب ربطه عبر خادم خلفي آمن، وعدم وضع مفتاح API في ملفات JavaScript العامة. المشاريع والملف المهني التجريبي محفوظان محليًا في المتصفح وقد يضيعان عند مسح بياناته.
