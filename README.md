# ANJIZ | أَنْجِز
واجهة عربية متجاوبة لمنصة إنجاز الأعمال الأكاديمية والمكتبية.

## رفع المشروع إلى GitHub Pages
ارفع محتويات هذه الحزمة إلى جذر المستودع `anjiz-platform`، مع استبدال الملفات القديمة. لا ترفع ملف ZIP داخل المستودع بدلًا من الملفات.

## الوظائف المتاحة في هذه النسخة
- واجهات منفصلة للترحيب والرئيسية والخدمات والمشاريع والمساعد وسوق المستقلين والملف الشخصي.
- حفظ المشاريع محليًا داخل متصفح الجهاز، وحذفها وتصدير نسخة احتياطية.
- وضع فاتح/داكن وأيقونات SVG مرسومة لكل خدمة.
- إعدادات PWA وأيقونة تطبيق مخصصة.

## حدود النسخة
الحسابات وتسجيل الدخول الاجتماعي، والمزامنة السحابية، وخدمات الذكاء الاصطناعي الفعلية، وطلبات المستقلين والدفع الإلكتروني غير موصولة بخادم في هذه النسخة. بيانات المشاريع محفوظة محليًا في المتصفح.
