# ANJIZ | أَنْجِز
حزمة واجهة أولية متجاوبة للهاتف والكمبيوتر، مع شاشة بداية، صفحة ترحيب، تنقل سفلي، خدمات، ومشاريع محفوظة محليًا.

## الرفع إلى GitHub Pages
1. فكّي ضغط ZIP.
2. افتحي مستودع `anjiz-platform` ثم `Add file → Upload files`.
3. ارفعي الملفات الموجودة داخل المجلد إلى جذر المستودع، وليس مجلد ZIP نفسه.
4. وافقي على استبدال الملفات المتطابقة وتأكدي من وجود `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js`, `anjiz-icon.svg`, `icon-192.png`, `icon-512.png`.
5. اكتبي رسالة commit: `Refresh ANJIZ mobile interface` ثم احفظي.
6. انتظري دقيقتين ثم افتحي الموقع. إذا بقيت نسخة قديمة، امسحي بيانات الموقع المؤقتة أو أزيلي التطبيق المثبت وثبتيه من جديد.

## حدود النسخة
حفظ المشاريع محلي على نفس الجهاز/المتصفح فقط. التسجيل الحقيقي، المزامنة السحابية، الذكاء الاصطناعي، سوق المستقلين والدفع الإلكتروني غير مفعّلة وتحتاج إلى خادم وقاعدة بيانات وخدمات آمنة. الترجمة الفرنسية والإنجليزية الكاملة غير متوفرة بعد.
