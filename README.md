# ANJIZ | أَنْجِز
منصتك لإنجاز أعمالك الأكاديمية والمكتبية.

## محتويات الحزمة
- `index.html` — الصفحة الرئيسية، شاشة البداية، الملف الشخصي والإعدادات، معاينة الحسابات والباقات.
- `styles.css` — التصميم المتجاوب للموبايل والكمبيوتر مع ألوان ANJIZ.
- `app.js` — تفاعلات الواجهة، حفظ المشاريع محليًا، إعداد اللغة والمظهر، ونوافذ الحساب والباقات التجريبية.
- `manifest.webmanifest` و`sw.js` — إعدادات PWA والتخزين المؤقت.
- `assets/anjiz-icon.svg` و`assets/icon-192.png` و`assets/icon-512.png` — أيقونة المنصة بأحجام مناسبة للويب والتثبيت.
- `UPLOAD_STEPS.txt` — خطوات رفع الملفات إلى GitHub Pages.

## مهم جدًا
هذه نسخة واجهة مطوّرة وليست خدمة إنتاج مكتملة. لا توجد حتى الآن حسابات حقيقية، أو قاعدة بيانات سحابية، أو اتصال فعلي بالذكاء الاصطناعي، أو مدفوعات. نماذج الحساب والباقات للتصميم والتجربة فقط ولا ترسل البيانات أو تخصم الأموال. لا تدخل كلمة مرور حقيقية في النموذج التجريبي.

## النشر
ارفع محتويات مجلد `ANJIZ` إلى جذر مستودع GitHub Pages، مع الحفاظ على مجلد `assets` كما هو. ثم من Settings > Pages اختر Deploy from a branch، والفرع `main` والمجلد `/(root)`.
