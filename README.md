# ANJIZ | أَنْجِز — حزمة الواجهة الأولية

## الملفات
- `index.html`: الصفحة الرئيسية والحوارات.
- `styles.css`: التصميم المتجاوب.
- `app.js`: التفاعلات، المشاريع المحلية، المظهر، اللغة، البحث، إخفاء شاشة البداية.
- `manifest.webmanifest`: إعدادات PWA.
- `sw.js`: التخزين المؤقت الأساسي.
- `anjiz-icon.svg`, `icon-192.png`, `icon-512.png`: الأيقونات.

## طريقة الرفع إلى GitHub
1. افتحي المستودع `anjiz-platform`.
2. حمّلي هذا الملف ZIP ثم فكّي ضغطه على الهاتف.
3. من المستودع اختاري **Add file → Upload files**.
4. ارفعي ملفات الحزمة الموجودة داخل المجلد، وليس مجلد الحزمة نفسه.
5. اختاري استبدال الملفات ذات الأسماء نفسها، وتأكدي أن `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js`, `anjiz-icon.svg`, `icon-192.png`, `icon-512.png` في جذر المستودع.
6. اكتبي في Commit changes: `Fix ANJIZ interface and PWA files` ثم احفظي.
7. انتظري دقيقة أو دقيقتين وافتحي الموقع من جديد. إذا ظهرت نسخة قديمة، حدّثي الصفحة تحديثًا قويًا أو امسحي بيانات الموقع المؤقتة.

## حدود النسخة
هذه واجهة أولية قابلة للتجربة. المشاريع تُحفظ محليًا على الجهاز. لا يوجد بعد تسجيل حسابات حقيقي، أو ذكاء اصطناعي متصل، أو سوق معاملات فعلي، أو دفع إلكتروني، أو مزامنة بين الأجهزة. هذه الوظائف تتطلب خادمًا وقاعدة بيانات وخدمات آمنة.
