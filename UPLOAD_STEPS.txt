دليل رفع ANJIZ إلى GitHub Pages من هاتف Android
================================================

مهم: GitHub Pages لا يشغّل ZIP مباشرة. يجب استخراج الملفات ورفعها إلى المستودع.

1. حمّل ZIP إلى الهاتف وافتح تطبيق الملفات (Files by Google أو مدير الملفات).
2. من Downloads اضغط ملف ZIP واختر استخراج/Extract. سيظهر مجلد ANJIZ.
3. افتح https://github.com وسجّل الدخول.
4. اضغط + ثم New repository. سمّه مثلًا anjiz-platform، واجعله Public إذا أردت استخدام GitHub Pages بالطريقة المجانية المعتادة، ثم أنشئه.
5. افتح المستودع واضغط Add file ثم Upload files.
6. من منتقي ملفات Android افتح مجلد ANJIZ المستخرج وحدّد الملفات والمجلد assets داخله: index.html وstyles.css وapp.js وmanifest.webmanifest وsw.js وREADME.md وUPLOAD_STEPS.txt ومجلد assets.
7. ارفع **المحتويات** إلى جذر المستودع، وليس مجلد ANJIZ نفسه. يجب أن يكون index.html ظاهرًا مباشرة في الصفحة الرئيسية للمستودع.
8. إذا لم تسمح واجهة الهاتف باختيار المجلدات أو عدة ملفات، افتح github.com في Chrome ثم قائمة ⋮ واختر Desktop site. قد تختلف الواجهة حسب الجهاز. إذا لم يظهر رفع assets، لا تكمل قبل رفعه. لا ترفع ZIP وحده.
9. اكتب رسالة مثل Add ANJIZ website ثم اضغط Commit changes.

تفعيل GitHub Pages
------------------
1. داخل المستودع افتح Settings ثم Pages.
2. تحت Build and deployment اختر Deploy from a branch.
3. اختر Branch: main والمجلد /(root)، ثم Save.
4. انتظر حتى يظهر رابط Pages في صفحة الإعدادات. غالبًا يكون https://اسم-حسابك.github.io/اسم-المستودع/ — استخدم الرابط الذي تعرضه GitHub فعلًا.
5. تأكد أن index.html في الجذر. إذا لم يعمل الموقع فورًا انتظر دقيقة أو دقيقتين وحدّث الصفحة.

اختبار الهاتف
-------------
- افتح رابط Pages على Android وجرّب القائمة ☰ والتمرير إلى الأقسام.
- افتح إحدى الخدمات، اكتب ملاحظات واحفظها كمشروع.
- أنشئ مشروعًا جديدًا، ثم جرّب Export TXT وحذف المشروع.
- جرّب البحث والمرشحات في سوق المحترفين؛ البطاقات أمثلة تجريبية.
- بدّل اللغة إلى Français وEnglish ثم العربية.
- افتح نموذج الانضمام واحفظ بيانات تجريبية. لن تُنشر على الإنترنت.
- إذا بقيت نسخة قديمة، أغلق الصفحة وأعد فتحها. إن استمر الأمر، امسح بيانات الموقع من إعدادات المتصفح ثم أعد فتح الرابط.

التثبيت كتطبيق (اختياري بعد نجاح الموقع)
---------------------------------------
افتح رابط HTTPS في Chrome على Android، ثم قائمة ⋮ وابحث عن إضافة إلى الشاشة الرئيسية أو تثبيت التطبيق. قد تختلف التسمية. ملف الأيقونة SVG مناسب للمتصفحات الحديثة، لكن قد تحتاج بعض الأجهزة إلى أيقونات PNG إضافية لتحسين التثبيت.

حدود النسخة
-----------
لا توجد حسابات أو قاعدة بيانات أو مزامنة، ولا تُنشر ملفات المحترفين ولا تُستقبل طلبات حقيقية. لا يوجد دفع أو عمولة فعلية. المساعد الذكي واجهة توضيحية فقط. المشاريع محفوظة محليًا على الجهاز/المتصفح وقد تفقد عند مسح بيانات المتصفح.
