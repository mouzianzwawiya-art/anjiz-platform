خطوات رفع نسخة ANJIZ الجديدة
1. فك ضغط الملف على هاتفك.
2. افتح مستودع anjiz-platform في GitHub.
3. اختر Add file ثم Upload files.
4. ارفع جميع الملفات والمجلدات الموجودة داخل الحزمة إلى جذر المستودع، وليس ملف ZIP نفسه.
5. في Commit changes اكتب: Redesign ANJIZ UI and app icon
6. اضغط Commit changes وانتظر حتى ينتهي نشر GitHub Pages.
7. افتح الموقع وحدّثه تحديثًا كاملًا. إذا كان مثبتًا كتطبيق، قد تحتاج إلى إغلاقه وإعادة فتحه لمسح النسخة القديمة من التخزين المؤقت.

مهم: الحسابات والذكاء الاصطناعي والدفع ليست مفعّلة في هذه النسخة.
